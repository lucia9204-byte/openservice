# 디지털서비스 개방관리

개통서비스명, 개방기관, 개통기업, 개통일자와 개방업무 추진단계를 관리하는 정적 웹 프로그램입니다.

## 실행

`dist/index.html`을 브라우저에서 엽니다. 자료는 해당 브라우저의 localStorage에 저장되며 서버나 GitHub에 업로드되지 않습니다. 다른 브라우저나 배포 주소로 옮길 때에는 백업·복원 기능을 사용하세요.

## Vercel 배포

GitHub의 이 저장소를 Import하고 Framework Preset은 Other, Root Directory는 저장소 루트로 설정합니다. 출력 폴더 `dist`는 vercel.json에서 지정합니다. 별도 설치 및 빌드 명령은 필요하지 않습니다.

## 기능

- 등록·수정·삭제 및 검색
- 개통 상태·추진단계·개통일자 필터
- CSV 내보내기 및 JSON 백업·복원
- 개통일자 선택 입력

여러 사용자의 데이터는 자동으로 공유되지 않습니다.
